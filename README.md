# Customer Segmentation — Czech Bank (Berka)

Сегментация банковских клиентов по транзакционной истории:
RFM-признаки считаются SQL-запросами в PostgreSQL, затем кластеризация
K-Means и бизнес-интерпретация полученных сегментов.

## Датасет

[Berka (PKDD'99)](https://www.kaggle.com/datasets) — реальные анонимизированные
данные чешского банка: ~4500 счетов, ~1 млн транзакций, 8 связанных таблиц
(клиенты, счета, транзакции, кредиты, карты).

Выбрал его по двум причинам:

1. **Реляционная схема.** RFM нельзя посчитать по одной таблице — придётся
   соединять клиентов, счета и транзакции. Главная цель проекта — прокачать
   SQL, и здесь JOIN'ы нужны по-настоящему, а не как упражнение.
2. **Финансовый домен.** Мой первый проект — [credit-risk-scoring]
   (https://github.com/rriizz2k/credit-risk-scoring) — про кредитный риск.
   Сегментация клиентов того же типа данных делает портфолио цельным
   и ближе к задачам финансовой аналитики.

## Стек

Python, PostgreSQL (Docker), SQL, pandas, scikit-learn, matplotlib, uv
